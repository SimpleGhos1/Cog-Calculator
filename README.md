This project is an app that gives you all the information for vanilla cogs in ToonTown Rewritten.
You can select the cog and level to see its attacks, hitpoints, promotion point value, and hit points. Also hit points.

The EXE file was made using Launch4j, which means youn have to have Java 25 JRE to launch it.
So if you have the JRE in C:\Users\YOURUSERNAMEHERE\.jdks\openjdk-25.0.1 it should run.
